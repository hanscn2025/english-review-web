# Dayword 小程序 UI 规范

## 设计原则

- 移动优先，单列内容，不使用桌面仪表盘式密度。
- 每屏只保留一个主任务；蓝色只用于主操作、选中态和关键信息。
- 图标全部使用同一套线性 SVG，不再用字体字符模拟图标。

## 颜色

- 品牌蓝：`#2563EB`；按下态：`#1D4ED8`；浅蓝背景：`#EFF6FF`。
- 主文字：`#101828`；正文：`#344054`；次要文字：`#667085`；弱提示：`#98A2B3`。
- 分隔线：`#E4E7EC`；浅底：`#F8FAFC`；辅助杏色：`#FFF1E6`。
- 页面背景保持白色。除错误、警告状态外，不新增临时颜色。

## 字体与行高

- 系统字体：`-apple-system, BlinkMacSystemFont, PingFang SC, sans-serif`。
- 页面主标题：48rpx / 1.25 / 700；导航标题：34rpx / 48rpx / 600。
- 分区标题：32rpx / 44rpx / 700；正文：28–30rpx / 1.5；辅助文字：23–25rpx / 1.5。
- 仅使用 400、600、700 三档字重，避免设备合成异常字形。

## 间距与尺寸

- 页面左右安全边距：48rpx；页面顶部导航安全区：224rpx。
- 基础间距：8rpx；常用间距为 16、24、32、40、48rpx。
- 表单控件最小高度：96rpx；主按钮：96rpx；触控区域不得小于 88rpx。
- 输入框圆角：24rpx；卡片圆角：32rpx；主任务卡片圆角：36rpx。
- 列表行高：144rpx；内容块之间用留白和 `#E4E7EC` 分隔。

## 页面结构

- 今日：首页标题 → 今日复习主卡 → 快速添加/翻译 → 七日打卡 → 我的词书。
- 翻译：语言方向 → 输入和语音/拍照入口 → 主翻译按钮 → 翻译结果。
- 词书：标题 → 新建词书 → 词书列表 → 规则说明。
- 添加：标题 → 内容类型 → 英文 → 中文 → 词书 → 音标/例句 → 保存。
- 复习：进度 → 英文语境 → 朗读 → 显示答案 → 释义 → 记忆评分。
- 我的：用户身份 → 学习统计 → 数据、语音和复习规则。
