# Dayword 微信小程序

## 导入

1. 微信开发者工具选择“导入项目”。
2. 项目目录选择仓库根目录，工具会读取根目录的 `project.config.json`。
3. AppID 已配置为 `wx9ba8079dba838c52`。

## 云开发

在微信开发者工具顶部点击“云开发”并创建环境，然后创建以下集合：

- `books`
- `entries`
- `review_logs`
- `daily_checkins`

每个集合使用“仅创建者可读写”权限。`database-rules.json` 保存了对应的权限规则参考。

没有云环境或集合时，小程序会自动使用本机测试数据，便于先验收交互；云环境可用后会自动使用云数据库。

## 语音

复习页会调用名为 `synthesizeSpeech` 的云函数，期望返回：

```json
{ "audioUrl": "https://..." }
```

语音云函数尚未绑定服务商密钥。未配置时界面会提示“语音服务尚未配置”，不会影响复习数据。
